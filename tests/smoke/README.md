# Сквозной автотест формы «ВсеФайлы»

> **Запуск отключён.** Фикстура запускала операции обработки по всей базе, а не
> только по созданным ею записям. До изоляции теста `run_smoke.sh` намеренно
> завершается с ошибкой; прежние результаты не подтверждают безопасность
> текущего продукта.

> **Относится к прежней сборке.** Фикстура нацелена на форму `Forms/ВсеФайлы`
> внутри `СозданиеАрхиваДокументооборота.epf`, которой в текущих исходниках уже
> нет: режим вынесен в `УправлениеАрхивомПрисоединенныхФайловОчисткаИВосстановление.epf`
> (`Forms/СписокФайлов`). Файлы этого каталога и `tests/smoke-result.txt` —
> артефакты прежней сборки; для новой обработки автотест **не перезапускался** и
> на неё не переносился. Проверка новой обработки — статические тесты
> `tests/test_archive_guards.py` и чек-лист
> `docs/testing/upravlenie-arhivom-acceptance.md`.

Автотест создаёт в тестовой базе синтетические данные и выполняет полный цикл:
анализ → архивирование → проверка → очистка → повторная очистка → восстановление →
повторное восстановление → конфликт → файл в томе → отказ очистки без проверки.

**Запускать только на выделенной тестовой базе.** Автотест удаляет содержимое
справочников `Файлы`, `ВерсииФайлов`, `ПапкиФайлов` и тестовых владельцев.

## Файлы

| Файл | Назначение |
|---|---|
| `autotest.bsl` | процедура `ВыполнитьАвтотест`, добавляемая в модуль формы |
| `run_smoke.sh` | сборка тестовой EPF, запуск 1С:Предприятия, открытие обработки, чтение результата |
| `xclick.py`, `xtype.py` | минимальная автоматизация X11 (XTest через ctypes) для закрытия стартовых окон и открытия EPF |

## Подготовка тестовой базы

```bash
ibcmd infobase create --db-path=<тестовая-база> --locale=ru
ibcmd infobase config import --db-path=<тестовая-база> /srv/dumps/hlev
ibcmd infobase config apply --db-path=<тестовая-база> --force
```

## Подготовка тестовой обработки

```bash
cp -a src /tmp/opencode/epf/smoke_src
# В корневом XML: DefaultForm = ...Form.ВсеФайлы
# В конец Forms/ВсеФайлы/Ext/Form/Module.bsl дописать autotest.bsl
# В ПриСозданииНаСервере добавить вызов ВыполнитьАвтотест();
```

Для БГУ в фикстуре `ФизическиеЛица` заменяется на `Организации`
(в БГУ нет справочника `ФизическиеЛицаПрисоединенныеФайлы`).

## Запуск

```bash
BASE=<тестовая-база> \
SRC=/tmp/opencode/epf/smoke_src/СозданиеАрхиваДокументооборота.xml \
OUT=/tmp/opencode/epf/build/smoke.epf \
tests/smoke/run_smoke.sh
```

Результат — `/tmp/opencode/epf/build/smoke-result.txt`.

## Почему нужна автоматизация X11

При первом запуске ЗКГУ/БГУ показывает «Начальное заполнение данных»,
«Начальная настройка программы» и «Интернет-поддержка пользователей», а при
открытии EPF — предупреждение безопасности. Скрипт закрывает их и открывает
обработку через Ctrl+O. Это нужно только для тестового стенда.
