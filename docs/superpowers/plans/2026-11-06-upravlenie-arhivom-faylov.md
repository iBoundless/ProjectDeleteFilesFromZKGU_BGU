# Управление архивом присоединённых файлов — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вынести сценарий «все присоединённые файлы» в отдельную внешнюю обработку с встроенным прогрессом, отбором по периоду и штатной отметкой «файл в архиве».

**Architecture:** Новый EPF `УправлениеАрхивомПрисоединенныхФайловОчисткаИВосстановление` получает копию формы `ВсеФайлы` и её модуля. Прогресс переносится на саму форму, серверная очистка разбивается на вызовы по одной записи, отбор по периоду добавляется в построение очереди, отметка `ДатаПереносаВАрхив` ставится в транзакции очистки и снимается в транзакции восстановления. Из исходной обработки форма удаляется.

**Tech Stack:** 1С:Предприятие 8.3.27.2214, формат выгрузки 2.20, БСП 3.1.12.297, внешняя обработка (EPF), Python `unittest` для статических проверок, PowerShell-скрипты валидации.

**Spec:** `docs/design/upravlenie-arhivom-faylov.md`

## Global Constraints

- Все изменяющие операции — только на копии базы. `bgu` и `hlev` не изменять; MCP `1S-Gate` только читает.
- В очередь, архив, очистку и восстановление попадают только записи с типом хранения `Перечисления.ТипыХраненияФайлов.ВИнформационнойБазе`. Тома, внешние и встроенные хранилища не читаются.
- `УсловноПеренесенВАрхив` никогда не выставляется в `Истина`.
- Отметка `ДатаПереносаВАрхив` ставится до удаления содержимого и снимается до записи содержимого, в той же транзакции.
- Проект **не является git-репозиторием**: шагов `git add`/`git commit` в плане нет. Контрольная точка каждой задачи — сборка и валидация.
- Версия формата выгрузки — `2.20`.
- Имя обработки: `УправлениеАрхивомПрисоединенныхФайловОчисткаИВосстановление`.
- Манифест: `formatVersion = 2`, `configName` — имя новой обработки. Манифесты прежней сборки не принимаются.

## Review Focus

- **Пустой период** — запись без владельца и без `ДатаСоздания` должна попасть в очередь, а не отфильтроваться молча.
- **Файл без версий** (`ТекущаяВерсия` пуста) — очистка проходит, отметки нет, в протоколе предупреждение, а не ошибка.
- **Владелец без реквизита `Дата`** (например, справочник) — берётся `ДатаСоздания` файла, запись не отбрасывается.
- **Полузаполненный период** (только начало или только конец) — работает как открытая граница.
- **Восстановление файла с оставшейся отметкой** — отметка снимается до записи содержимого, иначе БСП пытается распаковать файл как zip.
